# Pagina di installazione nel browser

`index.html` usa ESP Web Tools: un pulsante installa `../release/polpo-cardputer-0.1.0.bin` sul Cardputer da Chrome o Edge.

Per usarla deve essere servita in **https**. Il modo più semplice è GitHub Pages:

1. Sul repository GitHub apri **Settings**, poi **Pages**.
2. In **Source** scegli il branch che contiene la cartella `polpo`, cartella `/ (root)`, e salva.
3. Dopo qualche minuto apri `https://<utente>.github.io/<repository>/polpo/web/`.

GitHub Pages su repository privati richiede un piano a pagamento. In alternativa segui il metodo del manuale (`docs/MANUALE.md`, sezione 2) con il flasher web di Adafruit: è gratuito e funziona con il file `.bin` scaricato.
