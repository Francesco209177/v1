Installa il firmware Polpo

Per M5Stack Cardputer (v1.1 e Adv). Serve Chrome o Edge su computer e un cavo USB-C dati.

  1. Spegni il Cardputer con l'interruttore laterale.
  2. Tieni premuto il tasto G0 sul lato e collega il cavo USB, poi rilascia G0.
  3. Premi il pulsante qui sotto e scegli la porta del Cardputer.
  4. A installazione finita scollega il cavo e riaccendi.
Questo browser non supporta l'installazione via USB: usa Chrome o Edge su computer. Apri questa pagina da un indirizzo https (es. GitHub Pages), non da un file locale.

L'installazione cancella il firmware attuale del Cardputer. I file sulla microSD restano. Usa il Polpo solo su dispositivi tuoi.
