# Fronte Vostok

Sparatutto open world in prima persona con veicoli guidabili, scritto in HTML, CSS e JavaScript (Three.js).

- **Gioca:** scarica il repository (o [`FronteVostok.zip`](FronteVostok.zip)), estrai e apri `game/index.html`.
- **Online:** attiva GitHub Pages (Settings → Pages → branch `main`, cartella `/ (root)`) e apri `https://<utente>.github.io/v1/`.
- Comandi e dettagli: [`game/README.md`](game/README.md).
